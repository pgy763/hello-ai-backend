# 模型参数速查

只列**真的会改**的参数。厂商文档里那一长串，八成你一辈子不会碰。

> 参数名各家略有差异，下表按 OpenAI 兼容协议的常见叫法写；方括号里是别名。**以你用的厂商文档为准。**

## 一、最常用的五个

| 参数 | 典型范围 | 默认 | 调它会发生什么 |
| --- | --- | --- | --- |
| `temperature` | 0 – 2 | 1（部分厂商 0.7） | 越高越发散。**分类/抽取用 0**，创作类 0.7–1.0 |
| `top_p` | 0 – 1 | 1 | 与 temperature 二选一，别同时调 |
| `max_tokens` [`max_completion_tokens`] | 1 – 模型上限 | 模型上限 | 输出上限。**成本的第一道闸** |
| `stop` [`stop_sequences`] | 字符串数组 | 无 | 命中就停，能省 token、也能截断格式 |
| `stream` | true / false | false | 首字节从秒级降到百毫秒级 |

### temperature 怎么选

| 任务 | 值 | 理由 |
| --- | --- | --- |
| 分类、打标、抽取字段 | 0 | 你要的是稳定，不是创意 |
| 问答、摘要、改写 | 0.3 – 0.7 | 有点变化但不跑题 |
| 起名、文案、头脑风暴 | 0.8 – 1.2 | 需要发散 |
| 代码生成 | 0 – 0.3 | 越稳越好 |

**坑**：`temperature = 0` 不等于确定性输出。并发、批处理、上游版本变更都会让它变。要断言"同一输入同一输出"，得靠业务层的缓存或校验。

### max_tokens 怎么定

先量再定，别拍：

```
先跑 20 条真实样本，看输出 token 的 P95
max_tokens = P95 × 1.5（留余量给长尾）
```

设太小会**截断**（`finish_reason = "length"`），这比报错更危险 —— 用户看到的是一句没说完的话。

**判据**：日志里统计 `finish_reason` 分布，`length` 占比超过 1% 就说明上限偏小。

## 二、和成本直接相关的三个

| 参数 | 影响 | 注意 |
| --- | --- | --- |
| `max_tokens` | 输出成本 | 输出单价通常是输入的 2–4 倍 |
| prompt 长度 | 输入成本 | 每轮对话都会把历史重发一遍，**长对话成本是平方级增长** |
| 缓存前缀 | 输入成本 | 前缀缓存能省 20% 以上（第 8 章实测 21%），但前缀必须逐字节相同 |

## 三、容易被忽略的

| 参数 | 说明 |
| --- | --- |
| `seed` | 部分厂商支持，用于"尽力复现"。**不保证跨版本一致** |
| `response_format` [`json_mode`] | 要求输出 JSON。开了也可能被内容打断，仍要容错解析 |
| `tools` [`functions`] | 工具定义会算进输入 token，工具越多越贵 |
| `n` | 一次生成 n 个候选，成本 ×n。除评测外基本不用 |
| `logprobs` | 拿到每个 token 的概率，做置信度判断时有用 |

## 四、超时怎么设（不是模型参数，但同样关键）

| 层 | 建议 | 理由 |
| --- | --- | --- |
| 连接超时 | 5s | 连不上就是连不上，别耗 |
| 读超时（非流式） | 60–120s | 长回答真的会超过 30s |
| 读超时（流式） | 60s（首字节）；30s（字间隔） | 流式要分两段判 |
| 业务总超时 | 外层客户端超时之前 | 否则客户端已经放弃，你还在烧钱 |

**最外层的超时一定要大于内层重试的总时间**，否则重试还没跑完，客户端已经断开 —— 请求仍在计费。

## 五、一个真实的「参数不是主因」的例子

本书示例里唯一一次分类全错，原因不是温度、不是模型，而是**提示词**：

```
请给下面这条工单分类（退款/发票/物流/会员/其他），只输出类别：
<工单内容>
```

三张工单（退款、专票、物流）**全部**被分成「退款」—— 因为类别名就写在指令里，模型从整个 prompt 里找关键词，永远命中第一个。

改成「为下面的工单选一个类别，只输出类别名称：」之后，三张全对。

**教训**：分类/抽取不准时，先检查输入，再调参数，最后才换模型。参数能带来的提升，通常远小于一个提示词 bug 造成的损失。

> 本书没有做「temperature 对准确率影响」的量化实验 —— 那需要成规模的标注集，示例给不了可信数字。这类结论请自己用业务样本测。
