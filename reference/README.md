# reference

本书的**完整参考实现** —— 一个能跑的 AI 接入层。

正文只讲其中最关键的 50–100 行，这里的代码是完整的、可部署的那一版。

## 它包含什么

- 虚拟密钥与多租户额度
- 配置驱动的多模型路由
- 降级链与健康探测
- 熔断器 + Redis + Lua 令牌桶限流
- 基于状态机的多步任务编排（断点续跑、并发控制）
- token 计量、成本核算与调用审计
