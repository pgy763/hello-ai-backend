## 三条使用约定

1. **所有带「示例」字样的数字都不是厂商承诺** —— 价格、限流额度、超时默认值都会变，用之前查官方文档。
2. **厂商参数名不统一是常态**，同义词放在一起对照，别记成"标准"。
3. 这张表由本书示例倒推而来，**示例怎么写的，表就怎么写** —— 两边不一致时以示例为准，然后提个 issue。

## 想要完整实现？

`examples/` 下 12 个模块拼起来就是一个能跑的接入层，`14-capstone` 是它们的集成版。`reference/` 这里不再放一份代码，避免和示例产生两份会各自漂移的实现。

如果你想看更长的一版接入层（虚拟密钥、熔断、Redis 令牌桶、状态机编排全都有），可以看作者的 [llm-gateway](https://github.com/pgy763/llm-gateway)。
