# 第 8 章 · 可观测性：token 计量与成本核算

## 这一章解决什么问题

月底老板问：这个月 AI 花了多少钱？你说「应该不多」。这个回答在第一次超预算之后，就再也没用了。

## 你会得到

- 一份准确的调用日志，能回答「这条请求是谁发的、花了多少、用了多久」
- 一套成本核算模型，把 token 数换算成钱，并且支持不同模型不同单价
- 一个成本异常告警思路 —— 在账单爆炸之前收到通知

## 提纲

- **8.1 计量到底要记什么** —— 最少字段集，以及漏掉每一个会在什么时候卡住你
- **8.2 token 数从哪来** —— 响应里带的 `usage` 字段、流式下怎么拿、拿不到怎么办
- **8.3 单价表怎么维护** —— 模型改名、降价、阶梯定价，配置化的做法
- **8.4 成本归因** —— 一笔支出归到哪个业务线、哪个用户、哪个功能
- **8.5 异步落库不丢数据** —— 队列、批量写入，以及服务重启时怎么兜底
- **8.6 该看哪些指标** —— P95 延迟、token/请求、缓存命中率、失败率
- **8.7 告警线的设置** —— 日消耗突变、单次异常请求、失败率飙升
- **8.8 结论** —— 一张能直接抄的日志表字段清单
